## 注意事项

1. **不要跳过测试**: 除非有充分的理由，否则不要跳过任何测试
2. **修复失败的测试**: 不要提交有失败测试的代码
3. **保持测试更新**: 当功能变更时，更新相应的测试
4. **添加新测试**: 为新功能添加相应的测试
5. **文档同步**: 确保测试文档与实际测试保持同步

## 获取帮助

如果某个测试失败：
1. 查看测试输出和错误消息
2. 运行 `npm run test:ui` 或 `npm run test:e2e:ui` 进行调试
3. 查看 [tests/README.md](./README.md) 获取详细文档
4. 查看 [TESTING.md](../TESTING.md) 获取快速指南
5. 在团队中寻求帮助
